# 🇮🇳 India Social Explorer
Screenshot 2026-08-25 171012.png
An interactive data dashboard exploring population and literacy patterns across Indian states using Census 2011 data.

## 🌸 Live Demo

https://india-social-explorer-avuzud6msd4ykoyxnbxgay.streamlit.app/

## 📊 Features

- State-wise population analysis
- Overall literacy rates
- Male and female literacy rates
- Interactive India literacy map
- State-level explorer
- Highest and lowest literacy comparisons
- State-wise data table

## 🛠️ Tech Stack

- Python
- Pandas
- Streamlit
- Plotly
- GeoJSON
- Census 2011 data

## 📈 Data

The dashboard uses Census 2011 data to explore population and literacy patterns across Indian states and Union Territories.
